cozulmemisdosya

An automated content studio that produces original, fictional cold-case & unsolved-mystery short videos and publishes them to its owner's own social media accounts.

What cozulmemisdosya does

cozulmemisdosya is a personal content-automation tool. It writes original, fictional true-crime / cold-case stories, turns them into narrated vertical short videos (with atmospheric stock footage, captions and music), and then publishes those finished videos to the accounts owned by the operator of this project on TikTok, YouTube and Instagram. All characters and events are fictional; no real person or real case is named.

Features

Original stories

Each video is a unique, fictional cold-case script — no real names, no defamation, no copyrighted source material.

Automated production

Narration, subtitles, licensed stock footage, music and editing are assembled automatically.

Own-account publishing

Finished videos are posted only to the project owner's own connected accounts — never to third parties.

Copyright-safe media

Only royalty-free, license-cleared stock footage and music are used.

How TikTok is used

This application uses the TikTok Content Posting API for a single purpose: to upload the finished video files described above to the owner's own TikTok account, with the owner's authorization. The app does not read, collect, or repost other users' content, and it does not post to any account other than the authenticated owner's account.
